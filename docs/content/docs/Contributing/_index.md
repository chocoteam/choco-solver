Choco-solver is developed in the open on [GitHub](https://github.com/chocoteam/choco-solver), and contributions are welcome:
bug reports, feature requests, documentation and code.

## Ask a question

For questions about using the library, ask on the [Discord server](https://discord.gg/aH6zxa7e64).

## Report a bug or request a feature

Use the [issue tracker](https://github.com/chocoteam/choco-solver/issues).
For a bug, give the version you used and a
[minimal reproducible example](https://stackoverflow.com/help/minimal-reproducible-example).

## Improve the documentation

The pages of this documentation live in the choco-solver repository, in
[`docs/content/`](https://github.com/chocoteam/choco-solver/tree/develop/docs/content).
Every page has an **Edit this page** link that leads to its source: edit it and open a pull request against `develop`.

Code examples are not written in the pages: they are included from tested example files, in Java and in Python (pychoco).
[Writing documentation](https://github.com/chocoteam/choco-solver/blob/develop/docs/dev/documentation.md) explains how to add one.

## Contribute code

Read the [contribution guide](https://github.com/chocoteam/choco-solver/blob/develop/CONTRIBUTING.md)
and the [developer guide](https://github.com/chocoteam/choco-solver/tree/develop/docs/dev), which describes:

- the [architecture](https://github.com/chocoteam/choco-solver/blob/develop/docs/dev/architecture.md) of the library,
- how to [build and test](https://github.com/chocoteam/choco-solver/blob/develop/docs/dev/building-and-testing.md) it,
- the [best practices](https://github.com/chocoteam/choco-solver/blob/develop/docs/dev/best-practices.md)
  for constraints, propagators and tests.

Pull requests target the `develop` branch.
